# G08: Generador Algorítmico de Tablaturas Óptimas`n`nMotor modular para traducir secuencias musicales a tablaturas de guitarra ergonómicamente optimizadas mediante teoría de grafos y búsqueda multiobjetivo.`n`n## Arquitectura`n`n- `config/`: parámetros físicos del instrumento.`n- `data/`: entradas musicales y resultados generados.`n- `docs/`: paper y bibliografía.`n- `src/`: módulos de ingestion, dominio, grafos, optimización y presentación.`n- `tests/`: validación del podado anatómico, transformación dual y óptimalidad Pareto.`n`n## Uso`n`n1. Crear o activar el entorno virtual: `.venv``n2. Instalar dependencias: `pip install -r requirements.txt``n3. Ejecutar: `python main.py``n4. Probar: `pytest``n
